# Expense Management System

A responsive full-stack Expense Management System built with Python, Flask, SQLAlchemy, SQLite, HTML, CSS, JavaScript, Jinja2, and Chart.js.

## Features

- Complete CRUD operations
- Add, edit, delete, and view expenses
- Expense search
- Category filtering
- Amount and date sorting
- Date-range filtering
- Pagination
- Dashboard statistics
- Recent expenses overview
- Category-wise reports
- Monthly expense reports
- Interactive charts
- Responsive dashboard interface

## Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2
- Chart.js
